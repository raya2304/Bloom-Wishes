# Elegant Greeting Card

A beautiful and interactive digital greeting card created using **HTML, Tailwind CSS, and JavaScript**. The project features a soft floral design, interactive messages, animated hearts, wishes, and a responsive layout.

## Preview

A modern greeting experience with beautiful images, meaningful messages, smooth animations, and interactive elements.

## Features

* Elegant floral-themed design
* Responsive layout for all screen sizes
* Interactive greeting message
* Special note reveal animation
* Floating heart animations
* Reasons to Smile section
* Wishes section
* Beautiful Memories gallery
* Interactive "Send Some Love" button
* Smooth hover effects
* Modern card-based UI
* Single-page website

## Technologies Used

* HTML5
* Tailwind CSS
* JavaScript
* Unsplash Images

## Project Structure

```text
Elegant-Greeting-Card/
│
└── index.html
```

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No additional installation or setup is required.

## JavaScript Functionality

JavaScript is used to add interactive features such as:

* Opening and closing the special message
* Creating floating hearts dynamically
* Displaying surprise messages
* Sending an interactive love message
* Controlling animations and user interactions

## Design

The website uses a soft and elegant visual style with:

* Floral imagery
* Rounded cards
* Warm background tones
* Minimal typography
* Subtle shadows
* Interactive buttons
* Responsive layouts

## Customization

You can easily customize the card by changing:

* Recipient's name
* Greeting message
* Wishes
* Images
* Colors
* Footer text
* Button labels
* Special occasion details

The card can be adapted for:

* Birthday wishes
* Anniversary wishes
* Wedding wishes
* Congratulations
* Thank-you messages
* Friendship greetings
* Special occasions

This project was created as a front-end practice project to demonstrate the use of **HTML, Tailwind CSS, and JavaScript** to build an attractive and interactive web experience.
